# Rythmo – appli Android

Ce dépôt contient seulement le fichier d'installation de l'appli **Rythmo** (plans d'entraînement de course à pied). Le code source est privé.

**Installer ou mettre à jour :** sur votre téléphone Android, touchez le fichier `Rythmo.apk` ci-dessus, puis « Download » (ou « Télécharger »). Ouvrez le fichier téléchargé et touchez « Installer » ou « Mettre à jour ». Vos données restent sur votre téléphone.

Une fois installée, l'appli vous prévient d'elle-même quand une nouvelle version est disponible.
