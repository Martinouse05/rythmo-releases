# Rythmo – appli Android

Ce dépôt contient seulement les fichiers d'installation de l'appli **Rythmo** (plans d'entraînement de course à pied). Le code source est privé.

**Installer ou mettre à jour :** ouvrez la dernière version dans l'onglet *Releases*, téléchargez `Rythmo.apk` sur votre téléphone Android, ouvrez-le, puis touchez « Installer » ou « Mettre à jour ». Vos données restent sur votre téléphone.

Une fois installée, l'appli vous prévient d'elle-même quand une nouvelle version est disponible.
