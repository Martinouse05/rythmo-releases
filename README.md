# Rythmo – appli Android

Ce dépôt contient seulement le fichier d'installation de l'appli **Rythmo** (plans d'entraînement de course à pied).
Le code source est privé.

## Installer Rythmo

Sur votre téléphone Android, touchez le fichier `Rythmo.apk` ci-dessus, puis « Download » (ou « Télécharger »).
Ouvrez le fichier téléchargé et touchez « Installer ». Si Android le demande, autorisez l'installation depuis votre
navigateur.

Une fois installée, l'appli vous prévient d'elle-même quand une nouvelle version est disponible, et les mises à jour
s'installent par-dessus sans rien perdre.

## Vous aviez une version de test (0.15 ou avant) ?

La version 0.17 est la première version officielle : elle est signée avec une nouvelle clé, donc Android refuse de
l'installer par-dessus une version de test. À faire **une seule fois** :

1. **Sauvegarder** : dans l'ancienne Rythmo, Réglages → Sauvegarde → « Sauvegarder mes données », et rangez le fichier
   (Google Drive par exemple). Vérifiez qu'il est bien arrivé.
2. **Désinstaller** l'ancienne Rythmo (appui long sur l'icône → Désinstaller).
3. **Installer** la nouvelle version (`Rythmo.apk` ci-dessus).
4. **Restaurer** : sur l'écran d'accueil de la nouvelle Rythmo, touchez « J’ai une sauvegarde : restaurer mes données » et choisissez le fichier.
   Recollez ensuite votre clé intervals.icu et réactivez Health Connect si vous les utilisiez.

Votre ancienne version n'a pas de rubrique « Sauvegarde » (versions de test avant 0.14) ? Il n'y a pas de moyen de
transférer les données : désinstallez-la, installez la nouvelle et répondez de nouveau au questionnaire.
